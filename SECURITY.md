# Security Policy

## Supported versions

Only the latest version deployed from the `main` branch is supported.

## Reporting a vulnerability

Please **don't** open a public issue for security problems. Email **fazalabbas2002@gmail.com** instead, with:

- a description of the issue and its impact
- steps to reproduce, or a proof of concept
- the affected URL or file

You'll get a reply within 7 days. Once a fix ships, you'll be credited in the release notes unless you'd rather not be.

## Scope

Speed Type is a static, client-only site with no backend, accounts or stored data. The most relevant reports involve cross-site scripting, problems with the Content Security Policy or headers, and supply-chain issues in dependencies.
